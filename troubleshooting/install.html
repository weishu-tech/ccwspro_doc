安装与启动 ​

命令不存在 ​

现象：终端提示 command not found。

处理：

  1. 确认工具是否已安装。
  2. 关闭并重新打开终端。
  3. 检查 PATH 是否包含工具所在目录。

版本过旧 ​

现象：文档中的配置项不可用，或工具提示不支持某个参数。

处理：

bash
npm update -g

也可以按具体工具的官方升级命令执行。

启动后无响应 ​

优先检查：

  • 当前目录是否有项目文件。
  • 终端是否有权限访问项目目录。
  • 网络是否能访问 CCWS 接口地址。
