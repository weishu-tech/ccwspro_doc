# ChatGPT中转站使用说明书

这是面向用户的使用说明书，同一套步骤适用于控制台页面结构相同的中转站。

线上地址：[https://docs.ccws.pro](https://docs.ccws.pro)

## 内容定位

这份文档只解决用户使用过程中的实际问题，不做产品官网介绍，也不写内部实现细节。

用户使用自己的中转站网址。正文不要列出其他控制台地址，也不要暗示还可以换站。

重点按用户实际使用顺序组织：

1. ChatGPT 安装
2. 平台注册
3. 账号充值
4. API Key
5. 高级教程
6. 疑难解答

请求地址教「中转站网址 + `/v1`，或网站上专门说明的 API 地址」，写在 [配置 ChatGPT](docs/guide/connect.md) 里。入门配置侧边栏固定 6 章，不要为新内容单独加章。

## 写作口径

- 面向普通用户，步骤要直接、清楚、可照着操作。
- 请求地址教「中转站网址 + `/v1`，或网站上专门说明的 API 地址」，不要写死某一个控制台域名让所有人照抄。
- 截图优先使用真实控制台页面或真实工具界面。
- 不把说明书写成营销页，也不把 README 写成工程说明。
- 不向用户介绍或对比其他控制台站点。
