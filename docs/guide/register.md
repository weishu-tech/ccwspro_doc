# 注册 / 登录

这一页教你注册账号。注册好、能登录进控制台（管理账号的网页后台），就算完成了。目前只支持用账号密码注册登录。

打开**你的中转站网址**。中转站就是你用来登录、充值、创建 Key 的网站。

![注册页](/images/screenshots/register-account.png)

## 注册

1. 打开你的中转站网址。
2. 点右上角的「注册」或「开始使用」。
3. 按页面提示填账号和密码。
4. 再输一遍密码。
5. 点「创建账户」。

## 登录

注册完成后，回到登录页：

![登录页](/images/screenshots/login-account.png)

1. 打开登录页。
2. 输入用户名或邮箱。
3. 输入密码。
4. 点「登录」，进入控制台。

## 开始前准备

| 项目 | 说明 |
| --- | --- |
| 账号和密码 | 以后登录都要用，记下来、收好 |
| 浏览器 | 推荐用 Chrome、Edge、Safari 的最新版本 |
| 网络环境 | 页面一直打不开的话，先看看网络正不正常 |

::: tip 提示
如果页面提示要邀请码或人工审核，按页面说明提交申请，或者通过中转站的售后入口问一下开通方式。
:::

## 注册好了怎么确认

- 能进控制台。
- 能看到余额或套餐状态。
- 能进 API Key 管理页面。
- 能找到帮助入口或售后联系方式。

## 下一步

注册完、能登录了，接着去 [充值 / 续费](/guide/recharge)。
