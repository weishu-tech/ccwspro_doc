# 快速开始

这一页是**全部任务步骤的总览**。从安装到用上 ChatGPT，一共 6 步，大约 20 分钟。先把每一步是什么、怎么算完成看清楚，再一步步点进详细教程去做，心里就有底了。

::: tip 开始前先记住
后面注册、充值、填地址，一律用**你的中转站网址**。中转站就是你用来登录、充值、创建 Key 的网站。配置时，请求地址填中转站网址加 `/v1`，或网站上专门说明的 API 地址。
:::

## 第 1 步：安装 ChatGPT 桌面应用（含 Codex）

**干什么**：在电脑上装好 ChatGPT 桌面应用。Codex（AI 编程工具，你说话、它写代码）就在这个应用里，不用单独装。

**✅ 完成标志**：应用能正常打开，能看到主界面。

👉 详细教程：[安装 ChatGPT](/guide/codex-install)
🔧 卡住了：[疑难解答总览](/troubleshooting/)

## 第 2 步：注册账号

**干什么**：打开你的中转站网址，注册账号并登录。后面充值、创建 Key 都在这个网站的控制台（管理账号的网页后台）里操作。

**✅ 完成标志**：能进入控制台。

👉 详细教程：[注册 / 登录](/guide/register)

## 第 3 步：充值

**干什么**：在控制台的钱包页面充钱。ChatGPT 每次干活都会消耗余额，先充好钱后面才调得通。

**✅ 完成标志**：钱包余额大于 0。

👉 详细教程：[充值 / 续费](/guide/recharge)
🔧 卡住了：[付了钱没到账？](/guide/recharge#付了钱没到账)

## 第 4 步：创建 API Key

**干什么**：在控制台生成一串 API Key（读作"A-P-I-Key"，相当于一串密码，用来证明你有权限用这个服务）。第 5 步配置时要用它。

**✅ 完成标志**：复制到了一串以 `sk-` 开头的 Key。

👉 详细教程：[创建 API Key](/guide/api-key)

## 第 5 步：配置 ChatGPT

**干什么**：用一个叫 CC Switch 的小工具（有界面、能点鼠标），把请求地址和 API Key 填进 ChatGPT。这是最关键的一步。

**🎉 完成标志**：给 ChatGPT 发一条测试消息，它能正常回复你。**看到它回复，就说明全部配置完成了**，可以开始用了。

👉 详细教程：[配置 ChatGPT](/guide/connect)
🔧 卡住了：[网络与连接排查](/troubleshooting/network)

💡 **顺手了解（可选）**：CC Switch 还能管多个账号、多个配置之间切换：[CC Switch 使用教程](/guide/config-switch)。

## 第 6 步：生图功能（可选）

**干什么**：让 ChatGPT 生成、编辑图片，比如"帮我生成一张产品宣传图""把这张图改成某种风格"。

**✅ 完成标志**：发一个生图任务，ChatGPT 能生成图片。

👉 详细教程：[ChatGPT 生图教程](/guide/codex-image)

> 生图不是必须的，先把第 1～5 步跑通再说。

## 全部完成怎么确认

对照这张表，全部打勾就是完成了：

- ✅ 应用能正常打开
- ✅ 能进入控制台
- ✅ 钱包余额大于 0
- ✅ 复制到了一串 `sk-` 开头的 Key
- ✅ ChatGPT 能正常回复你的测试消息

前面 4 项是准备材料，最后一项是验收。**看到 ChatGPT 回复你，就可以开始用了**，之后遇到问题随时去 [疑难解答总览](/troubleshooting/) 按症状查。
