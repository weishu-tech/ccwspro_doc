# 售后与支持

当用户在注册、充值、Key 配置或工具调用中遇到问题时，通过**你的中转站**提供的售后渠道联系。

## 怎么联系

1. 登录你的中转站控制台。
2. 在页面里找「帮助」「客服」或售后入口。
3. 如果工作人员已经拉你进售后群，就用那个群。不要根据网上搜到的群号自行加群。

## 建议提供的信息

提交问题前，请准备：

- 账号邮箱或手机号。
- 问题发生时间。
- 报错截图或完整错误信息。
- 使用的工具名称和版本。
- 已尝试过的排查步骤。

## 支持渠道

| 渠道 | 用途 | 响应说明 |
| --- | --- | --- |
| 控制台帮助 / 售后群 | 账号、充值、Key 配置、工具调用问题 | 以你的中转站公布的入口为准 |
| 商务合作 | 企业采购、渠道合作、培训服务、工作流定制、软件定制 | 请通过 [商务合作](/guide/business) 页面说明需求 |
