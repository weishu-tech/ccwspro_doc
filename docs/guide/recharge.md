# 充值 / 续费

这一页讲怎么给账号充钱、续套餐，以及付完款怎么确认到账。请在**你的中转站**控制台里操作。

![充值页面](/images/screenshots/wallet-recharge.png)

## 充值

1. 登录控制台。
2. 进「钱包」页面。
3. 在「添加资金」区域选一个固定金额，或者自己填一个金额。
4. 选支付方式（目前支持支付宝）。
5. 看清楚金额，付款。
6. 回控制台，确认余额已经更新。

## 兑换码兑换

有兑换码的话，在钱包页面底部就能换：

![兑换码兑换](/images/screenshots/wallet-redeem-code.png)

1. 找到「有兑换码吗？」那一栏。
2. 输入兑换码。
3. 点「兑换额度」。
4. 兑换完刷新一下页面，确认额度到账了。

## 付了钱没到账

遇到付款后余额没变，按这个顺序查：

- 等 1 到 3 分钟，刷新页面再看看。
- 查一下支付订单是不是成功了。
- 把订单号、付款截图和账号信息都存好。
- 通过你的中转站售后入口联系处理。
