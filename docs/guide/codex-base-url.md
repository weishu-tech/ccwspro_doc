# ChatGPT Base URL 怎么填

::: tip 📌 页面已合并
本页内容已合并到 **[配置 ChatGPT](/guide/connect)**，完整的请求地址填写说明和验证步骤都在新页面里。
:::

快速回顾关键信息：

- **请求地址（Base URL）**：你的中转站网址 + `/v1`，或网站上专门说明的 API 地址
- **官网 / 网站地址**：填你的中转站网址（只有字段明确要求 Base URL 时才填请求地址）
- **不要**填成 `.../v1/chat/completions`
- 网站没有专门说明 API 地址时，**不要**漏掉 `/v1`
- **填完必须重启 ChatGPT**，不然它还在读旧配置

👇 直接去 [配置 ChatGPT](/guide/connect) 开始。
